# 경달이 고딩 생존일기 - GitHub Pages 모바일 업로드 경량판

## 업로드 방법
1. 이 ZIP을 **압축 해제**합니다.
2. 저장소의 `Add file > Upload files`로 **index.html, data.json, .nojekyll, images 폴더, 경달이_이모티콘_72종_전체다운로드.zip**을 업로드합니다.
3. Settings > Pages > Deploy from a branch > main / (root) 저장.
4. GitHub Pages 주소로 확인합니다.

원본 72장 대신 화면·다운로드용 이미지를 최대 512px, PNG 투명 배경, 192색으로 최적화했습니다.
고해상도 원본은 기존 사용자가 제공한 72종 ZIP에 보존되어 있습니다.
휴대폰 브라우저에서 파일 대량 선택이 실패하면 PC를 이용하거나 2~3회로 나눠 업로드하세요.
