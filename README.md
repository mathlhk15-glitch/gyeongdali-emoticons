# 경달이의 고딩 생존일기 | 72종 이모티콘 웹사이트

GitHub Pages에 올리는 정적 웹사이트입니다. **72종 PNG, 72종 미리보기, 전체 다운로드 ZIP**을 포함합니다.

## 배포하기
1. GitHub에서 공개(Public) 저장소를 만듭니다. (예: `gyeongdali-emoticons`)
2. 이 배포 ZIP을 압축 해제한 다음 **내부의 모든 파일과 폴더**를 저장소 최상위(root)에 업로드합니다. ZIP 자체만 업로드하면 작동하지 않습니다.
3. `Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: main / (root) → Save`를 선택합니다.
4. 잠시 뒤 `https://계정.github.io/gyeongdali-emoticons/`에서 접속할 수 있습니다. (계정과 저장소 이름에 따라 주소가 달라집니다.)

## 파일
- `index.html`: 반응형 사이트 및 다운로드 기능
- `data.json`: 72종 목록/분류
- `images/01.png` ~ `images/72.png`: 원본 투명 PNG
- `thumbs/01.png` ~ `thumbs/72.png`: 빠른 미리보기
- `경달이_이모티콘_72종_전체다운로드.zip`: 방문자용 전체 이미지 다운로드 (480px, 각 원본은 개별 다운로드로 제공)

## 검수 유의사항
원본 ZIP에는 이름이 손상된 항목이 있어 01~72로 보존/정규화했습니다. 조끼의 작은 교표·연도 문구 등은 공식 이미지와 차이가 있을 수 있습니다. 학교 이름 및 마스코트 저작권 사용 권한을 확인한 후 공식 배포하세요.

로컬에서 HTML을 바로 열면 JSON 로딩이 브라우저 정책에 막힐 수 있으므로 GitHub Pages에서 테스트하세요.
